# XG-200KI（HGW）設定手順書

XG-200KI はテキストconfigを持たないため、**Web管理画面での操作手順**として記載します。

> **機器補足**：XG-200KI は XG-100NE の後継として NTT東日本／西日本が提供するフレッツ光クロス対応HGW（2026年5月提供開始・**Wi-Fi 7 / 11be** 対応）。**有線ポート構成はXG-100NEと同一**（WAN 10G×1／10G対応はLAN4のみ／LAN1〜3は1G／RJ-11×2）で、本手順書の結線・運用はXG-100NEから変更ありません。「アダプタモード」を持ちますが、これは**ひかり電話オフィスタイプ／オフィスA向けの専用モード**（切替は工事保守者のみ）で、本構成（通常のひかり電話・ルータモード）では**使用しません**。
>
> **重要（ONUは別体）**：**XG-200KIはONU一体型ではありません。** フレッツ光クロスでは前段に別体の **10G-EPON ONU（光加入者終端装置・箱型）** が必ず設置され、その10GBASE-T端子とXG-200KIの**WAN端子（10GBASE-T RJ-45）**をCAT6Aで接続します（`光ファイバ → ONU → XG-200KI → RTX1300` の3段）。

- 設計根拠：[[社内LANネットワーク設定]]（3-1、XG-200KIポート使用図、IPv6アドレス配布方式）
- 切替当日の位置づけ：[[切替・障害切り分け手順]] の「3-1. 物理接続」ステップ2〜5

---

## 0. 設定方針（1行まとめ）

**XG-200KIはルータ機能を使わず、LAN4からRTX1300へ渡すだけの経路にする。** ただし完全なブリッジモードは存在しないため、LAN側 `192.168.1.1/24` とDHCPサーバは動作し続ける。

## 1. 管理画面へのアクセス

| 項目       | 値                                              |
| -------- | ---------------------------------------------- |
| URL      | `http://192.168.1.1/`（または `http://ntt.setup/`） |
| 接続方法     | **保守用端末をXG-200KIのLAN1〜3のいずれかへ一時直結**            |

> 常設の管理経路は設けません。設定変更・障害切り分け時のみ直結し、作業後はケーブルを撤去します。

## 2. 設定項目チェックリスト

### 2-1. 無線LAN（Wi-Fi）— 常時OFF

- [x] 2.4GHz帯のSSID発信を **OFF（無効）**
- [x] 5GHz帯のSSID発信を **OFF（無効）**
- [x] **6GHz帯のSSID発信を OFF（無効）**（XG-200KIはWi-Fi 7対応で6GHz帯を持つため）

> 社内無線はBE9400に集約するため、平常時・メンテナンス時とも使用しません。不要な電波の抑制と、意図しない経路の排除が目的です。XG-200KIはWi-Fi 7（2.4／5／**6GHz**）対応のため、**3帯域すべて**をOFFにします。

### 2-2. ルータ機能 — 接続先設定を投入しない

- [x] **接続先設定（プロバイダ設定）を登録しない**
- [x] 既に登録済みの場合は **削除する**

> IPv4 over IPv6 の終端は RTX1300 が行います。ここに接続先設定が残っていると**二重ルータ**になり、RTX1300が固定グローバルIPを保持できません。

### 2-3. LAN側設定 — 既定のまま変更しない

- [x] LAN側IPアドレス `192.168.1.1/24` は **変更しない**
- [x] LAN側DHCPサーバは **既定のまま**（保守端末の一時接続に使用）

> `192.168.1.0/24` は社内VLANのどのセグメントとも重複していません（VLAN10=128 / VLAN20=64 / VLAN30=192 / 保守=200）。**社内セグメントを `192.168.1.x` にすることは禁止**です。

### 2-4. IPv6 — 既定のまま

- [x] IPv6の設定は既定のまま（変更しない）

> XG-200KIがNTT網から **DHCPv6-PD** でプレフィックスを取得し、LAN側へ **RAで /64 を1本広告**します。配下ルータへのプレフィックス再委任は行われません。
> このため **RTX1300側は「RA方式」で設定**します（→ [[社内LANネットワーク設定]] 3-6の直前セクション）。

### 2-5. ひかり電話

- [x] **通常のひかり電話（確定）**：電話機は **XG-200KI のRJ-11ポートへ直接接続**（ルータモードのまま）。
- [x] ひかり電話は**ルータモードで動作**するため、アダプタモードへの切替は不要（＝工事保守者への依頼も不要）。

> オフィスタイプ／オフィスAではないため、**アダプタモードは使用しません**。ひかり電話・インターネットとも通常のルータモードで併存します（接続先設定は投入しない運用のまま）。

## 3. ポート結線

| ポート                        | 接続先                                  | 平常時の使用                   |
| -------------------------- | ------------------------------------ | ------------------------ |
| **WAN**（10GBASE-T / RJ-45） | **10G-EPON ONU の10GBASE-T端子**（CAT6A） | **常時使用**（前段にONUが必須）      |
| **LAN4**（10GBASE-T）        | **RTX1300 LAN2 RJ-45**（CAT6A）        | **常時使用**                 |
| LAN1〜3（1000BASE-T）         | 未接続                                  | **メンテナンス時のみ**（管理端末を一時直結） |

```
光ファイバ → [10G-EPON ONU] --CAT6A--> [XG-200KI WAN] →(内部)→ LAN4 --CAT6A--> RTX1300 LAN2

| XG-200KI | WAN | LAN1 | LAN2 | LAN3 | LAN4 |
| 平常時   | ●   |  -   |  -   |  -   |  ●   |
| 保守時   | ●   | 管理端末をいずれか1ポートへ一時接続 |  ●   |
```

## 4. 設定後の確認

|   # | 確認内容               | 方法                           | 期待結果                        |
| --: | ------------------ | ---------------------------- | --------------------------- |
|   0 | ONUの状態／WANリンク      | ONU前面ランプ、XG-200KI管理画面のWAN状態  | ONUのランプ正常（認証・光回線）、WANリンク up |
|   1 | Wi-Fiが停止しているか      | スマートフォンでSSIDを検索              | XG-200KIのSSIDが見えない          |
|   2 | LAN4のリンク           | RTX1300側で `show status lan2` | Link up / 10Gbps / Full     |
|   3 | 接続先設定が無いこと         | 管理画面の接続先設定一覧                 | 未登録                         |
|   4 | RTX1300がRAを受信しているか | RTX1300で `show ipv6 address` | LAN2にグローバルIPv6アドレスがある       |

> 4がNGの場合は、XG-200KIの再起動 → 5分待って再確認。それでもNGならNTT東日本 故障受付（`0120-594-202`）へ。

## 5. 注意事項

- **XG-200KIはONU一体型ではありません。** 光クロスでは前段に別体の **10G-EPON ONU（光加入者終端装置・箱型）** が設置され、`ONU – XG-200KI – RTX1300` の3段が必須構成です（ひかり電話契約の有無に関わらず同構成／撤去・バイパス不可）。
- **完全なブリッジモードはありません。** PR-500KI等の「PPPoEブリッジ」に相当する透過モードは存在しないため、「接続先設定を入れない」という運用で二重ルータを回避します（XG-200KIの「アダプタモード」は**ひかり電話オフィス系専用**でありインターネット用の透過モードではありません）。
- **UPS保護対象**：**ONU と XG-200KI の2台分**をUPS保護に含めます（**ONU停電＝インターネット全断**のため）。**UPSは8個口あり口数の不足なし（確認済）**。ONUは DC12V/0.7A（≈8.4W・ACアダプタ給電）で負荷影響も軽微。
- **ONU↔XG間のCAT6Aケーブルは ONU に付属**（別途手配不要・確認済）。
- **管理IP（`192.168.1.1`）は初回アクセス時に実機で確認**します（NTT標準の初期値で継続の想定）。
- **ONU諸元（実機ラベル・2026-09-09確認）**：
  - 部品名：`10G-EPON〈0〉C ONU〈4〉`（実機ラベル表記）
  - 仕様書番号：仕160043号 ／ 製造年月：2026-05 ／ 製造番号：`2605H018553`
  - 定格：DC12V・0.7A ／ 製造：日本電信電話（会社コード403）
  - MACアドレス：`00:11:57:72:AC:62`
  - ※NTTへ故障申告する際は **製造番号・MAC** を提示。
