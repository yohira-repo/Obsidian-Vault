# XG-100NE（HGW）設定手順書

XG-100NE はテキストconfigを持たないため、**Web管理画面での操作手順**として記載します。

- 設計根拠：[[社内LANネットワーク設定]]（3-1、XG-100NEポート使用図、IPv6アドレス配布方式）
- 切替当日の位置づけ：[[切替・障害切り分け手順]] の「3-1. 物理接続」ステップ2〜5

---

## 0. 設定方針（1行まとめ）

**XG-100NEはルータ機能を使わず、LAN4からRTX1300へ渡すだけの経路にする。** ただし完全なブリッジモードは存在しないため、LAN側 `192.168.1.1/24` とDHCPサーバは動作し続ける。

---

## 1. 管理画面へのアクセス

| 項目 | 値 |
|---|---|
| URL | `http://192.168.1.1/`（または `http://ntt.setup/`） |
| 接続方法 | **保守用端末をXG-100NEのLAN1〜3のいずれかへ一時直結** |
| 端末側のIP設定 | 自動取得（DHCPで `192.168.1.x` を取得） |
| 管理者ユーザー名 | **要記入**（初回アクセス時に設定） |
| 管理者パスワード | **要記入**（初回アクセス時に設定） |

> 常設の管理経路は設けません。設定変更・障害切り分け時のみ直結し、作業後はケーブルを撤去します。

## 2. 設定項目チェックリスト

### 2-1. 無線LAN（Wi-Fi）— 常時OFF

- [ ] 2.4GHz帯のSSID発信を **OFF（無効）**
- [ ] 5GHz帯のSSID発信を **OFF（無効）**

> 社内無線はBE9400に集約するため、平常時・メンテナンス時とも使用しません。不要な電波の抑制と、意図しない経路の排除が目的です。

### 2-2. ルータ機能 — 接続先設定を投入しない

- [ ] **接続先設定（プロバイダ設定）を登録しない**
- [ ] 既に登録済みの場合は **削除する**

> IPv4 over IPv6 の終端は RTX1300 が行います。ここに接続先設定が残っていると**二重ルータ**になり、RTX1300が固定グローバルIPを保持できません。

### 2-3. LAN側設定 — 既定のまま変更しない

- [ ] LAN側IPアドレス `192.168.1.1/24` は **変更しない**
- [ ] LAN側DHCPサーバは **既定のまま**（保守端末の一時接続に使用）

> `192.168.1.0/24` は社内VLANのどのセグメントとも重複していません（VLAN10=128 / VLAN20=64 / VLAN30=192 / 保守=200）。**社内セグメントを `192.168.1.x` にすることは禁止**です。

### 2-4. IPv6 — 既定のまま

- [ ] IPv6の設定は既定のまま（変更しない）

> XG-100NEがNTT網から **DHCPv6-PD** でプレフィックスを取得し、LAN側へ **RAで /64 を1本広告**します。配下ルータへのプレフィックス再委任は行われません。
> このため **RTX1300側は「RA方式」で設定**します（→ [[社内LANネットワーク設定]] 3-6の直前セクション）。

### 2-5. ひかり電話

- [ ] ひかり電話の契約有無と、電話機の接続要否を確認 → **要記入**

## 3. ポート結線

| ポート | 接続先 | 平常時の使用 |
|---|---|---|
| 光ポート（WAN） | フレッツ光クロス回線 | **常時使用** |
| **LAN4**（10GBASE-T） | **RTX1300 LAN2 RJ-45**（CAT6A） | **常時使用** |
| LAN1〜3（1000BASE-T） | 未接続 | **メンテナンス時のみ**（管理端末を一時直結） |

```
| XG-100NE | 光 | LAN1 | LAN2 | LAN3 | LAN4 |
| 平常時   | ●  |  -   |  -   |  -   |  ●   |
| 保守時   | ●  | 管理端末をいずれか1ポートへ一時接続 |  ●   |
```

## 4. 設定後の確認

| # | 確認内容 | 方法 | 期待結果 |
|---:|---|---|---|
| 1 | Wi-Fiが停止しているか | スマートフォンでSSIDを検索 | XG-100NEのSSIDが見えない |
| 2 | LAN4のリンク | RTX1300側で `show status lan2` | Link up / 10Gbps / Full |
| 3 | 接続先設定が無いこと | 管理画面の接続先設定一覧 | 未登録 |
| 4 | RTX1300がRAを受信しているか | RTX1300で `show ipv6 address` | LAN2にグローバルIPv6アドレスがある |

> 4がNGの場合は、XG-100NEの再起動 → 5分待って再確認。それでもNGならNTT東日本 故障受付（`0120-594-202`）へ。

---

## 5. 注意事項

- **XG-100NEは撤去・バイパスできません。** 固定IPサービスでは、ひかり電話契約の有無に関わらず `ONU – XG-100NE – ルータ` が必須構成です。
- **完全なブリッジモードはありません。** PR-500KI等の「PPPoEブリッジ」に相当する透過モードは存在しないため、「接続先設定を入れない」という運用で二重ルータを回避します。
- **UPS保護対象**に含めます（電源口・ラックスペース1台分）。
