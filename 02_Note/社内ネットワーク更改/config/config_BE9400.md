# NETGEAR WBE710（BE9400）設定手順書（無線AP）

WBE710（BE9400）は **Wi-Fi 7・トライバンド（2.4／5／6GHz）・2.5GbE + PoE 対応のアクセスポイント**です。テキストconfigではなく、**ローカルWeb管理画面**で設定します（NETGEAR Insightは使用しない）。

- 設計根拠：[[社内LANネットワーク設定]]（無線LAN SSID・VLAN設計、PoEエクステンダー ポート使用図、3-3 固定IP割当）
- 関連：[[config_XS508TM]] / [[config_RTX1300]] / [[config_XG-200KI]]
- 切替当日の位置づけ：[[切替・障害切り分け手順]]（無線LANの疎通確認ステップ）

---

## 0. 設定方針（1行まとめ）

**上位（XS508TM Port5 → PoEエクステンダー）からタグVLAN 10・20・30を受け、SSIDごとに1つのVLANへ振り分ける。** ルーティング・DHCPは行わず、AP自身は**L2ブリッジ**として動作させる（各VLANのGW・DHCPはRTX1300）。

---

## 1. 管理設定

| 項目          | 値                                 |
| ----------- | --------------------------------- |
| 管理IPアドレス    | `192.168.128.3/24`（**固定**）        |
| デフォルトゲートウェイ | `192.168.128.1`（RTX1300 VLAN 10）  |
| 管理VLAN      | **VLAN 10（ネイティブ/アンタグ）**（AP側 Untagged VLAN=10・Management VLAN=10） |
| DNS         | パブリックDNS（RTX1300・XS508TMと同じもの）    |
| 管理者パスワード    | **要記入**（初期パスワードから必ず変更）            |
| 管理方式        | **ローカルWeb GUIで確定**（NETGEAR Insightは使用しない） |
| 時刻同期（NTP）   | 有効（ログ・証明書の整合のため）                  |

> **管理IPは固定にします。** DHCP取得のままだとVLAN設定変更後に管理画面を見失う恐れがあります。管理IP `192.168.128.3` は [[社内LANネットワーク設定]] 3-3 で確定済み（XS508TM=`.2` と連番）。
> AP管理はVLAN 10（Office）上で行います。実機UIに合わせ **VLAN10はネイティブ（アンタグ）** とします：AP側 **Untagged VLAN=10／Management VLAN=10**、SSIDは Office=10／Develop=20／Guest=30。アップリンク（XS508TM Port5）は **VLAN10＝アンタグ(U)＋PVID10、VLAN20/30＝タグ(T)**。VLAN10（管理＋Office）はアンタグで送受、20/30はタグ。※フラット→VLAN移行が滑らか（アンタグのままIPだけ変わる）。

## 2. 無線（RF）設定方針

| 帯域 | 用途 | 設定 |
|---|---|---|
| 2.4GHz | 互換端末・IoT | 有効（チャネルは自動、必要に応じ固定） |
| 5GHz | 主力帯域 | 有効（DFS帯の使用可否は環境確認のうえ決定） |
| 6GHz | Wi-Fi 7主力（対応端末） | 有効 |

- **チャネル／出力は初期は自動**とし、干渉状況を見て調整します（単一AP構成のため隣接AP設計は不要）。
- **バンドステアリング**：有効（対応端末を上位帯域へ誘導）。
- 各SSIDのトライバンド展開可否は端末要件に合わせて調整（ゲストは2.4/5GHzのみでも可）。

## 3. SSID・VLAN設計（本設定の中核）

SSIDごとに接続先VLANを分けます。無線端末は接続SSIDに応じて各セグメントへ収容されます。

| SSID | 用途 | 割当VLAN | 収容セグメント | セキュリティ | 分離 |
|---|---|---:|---|---|---|
| `Office-WiFi` | 営業・総務管理 | **VLAN 10** | `192.168.128.0/24` | WPA3（またはWPA2/3混在）＋要記入PSK | － |
| `Develop-WiFi` | 開発・試験 | **VLAN 20** | `192.168.64.0/24` | WPA3（またはWPA2/3混在）＋要記入PSK | － |
| `Guest-WiFi` | ゲスト専用 | **VLAN 30** | `192.168.192.0/24` | WPA2/WPA3＋要記入PSK | **クライアント分離ON** |

```text
Office-WiFi  → VLAN 10（営業・総務管理）
Develop-WiFi → VLAN 20（開発）
Guest-WiFi   → VLAN 30（ゲスト / 社内VLAN 10・20から分離）
```

### 設定要点

- 各SSIDに **「VLAN ID」＝10／20／30 を明示的に割り当て**ます（タグ付き送出）。
- **DHCPはAPで動かさない**（IPアドレス・GW・DNSは各VLANのRTX1300が配布）。
- **Guest-WiFi（VLAN30）**：
  - **クライアント分離（AP isolation／Client isolation）をON**にし、ゲスト端末同士の通信も遮断します。
  - VLAN 30 → VLAN 10・20 の遮断は**RTX1300のフィルタ**で実施済み（[[config_RTX1300]]／[[社内LANネットワーク設定]] 3-4）。APは正しいVLANへ載せるだけでよく、AP側でのゲスト用URLフィルタ等は任意。
- SSID名・PSKは**要記入**（本ファイルには秘匿情報を平文で残さない）。運用パスワードは別途パスワード管理台帳へ。

## 4. 有線アップリンク／ポート結線

| ポート | 接続先 | 内容 |
|---|---|---|
| LAN（PoE入力・2.5GbE） | **PoEエクステンダー EIB-X01A-BT6 OUT** → 上流は XS508TM Port5 | **タグVLAN 10・20・30 を受ける**／PoE受電（802.3bt / 最大60W給電） |

```
XS508TM Port5 ──(2.5GbE, タグVLAN 10/20/30)──▶ EIB-X01A-BT6 IN
EIB-X01A-BT6 OUT ──(2.5GbE + PoE(802.3bt,最大60W), VLANタグ透過)──▶ WBE710(BE9400, 最大約25W)
```

- 上流 **XS508TM Port5**：**VLAN10＝アンタグ(U)＋PVID10、VLAN20/30＝タグ(T)**（[[config_XS508TM]] 3-1）。
- **PoEエクステンダーはVLANタグを変更せず透過**します（[[社内LANネットワーク設定]] PoEエクステンダー ポート使用図）。
- AP側アップリンクでは **VLAN10＝アンタグ（ネイティブ）**、**VLAN20/30＝タグ**として送受します。**管理＝VLAN10（アンタグ/ネイティブ）**。Port5のVLAN10もアンタグ(U)＋PVID10に合わせること（AP側 Untagged VLAN=10）。

## 6. 設定後の確認

| # | 確認内容 | 方法 | 期待結果 |
|---:|---|---|---|
| 1 | 管理画面到達 | VLAN 10端末から `https://192.168.128.3/` | ログインできる |
| 2 | Office-WiFi | 接続して取得IPを確認 | **192.168.128.x**（VLAN10）を取得 |
| 3 | Develop-WiFi | 接続して取得IPを確認 | **192.168.64.x**（VLAN20）を取得 |
| 4 | Guest-WiFi | 接続して取得IPを確認 | **192.168.192.x**（VLAN30）を取得 |
| 5 | ゲスト分離 | Guest-WiFiから `192.168.128.x`／`192.168.64.x` へアクセス | **到達不可**（RTX1300で拒否） |
| 6 | インターネット | 各SSIDから外部サイトへ接続 | Office/Develop/Guestとも疎通あり |
| 7 | PoE受電 | APのLED／XS508TM側のPoE給電表示 | 正常給電 |

> 2〜4で**IPが取得できない／別VLANのIPを取得する**場合は、①APのSSID-VLAN割当、②XS508TM Port5のタグ設定、③PoEエクステンダーの透過、の順で確認します。
> 5がNG（ゲストから社内へ到達できる）の場合は、APではなく **RTX1300のフィルタ**を確認（[[config_RTX1300]]）。

## 7. 注意事項・要確認

- **給電方式（確定・充足）**：給電は **PoEエクステンダー EIB-X01A-BT6（IEEE 802.3bt / 最大60W給電）** で行い、WBE710（BE9400）の消費電力は最大約25W。**60W ≫ 25W で給電能力は十分**です（Wi-Fi 7フル機能時のPoE++要件も満たす）。給電不足によるリンク不安定・帯域停止の懸念はありません。
- **管理IPの重複禁止**：`192.168.128.3` はAP専用。XS508TM=`.2`／複合機=`.20` と重複させないこと（[[社内LANネットワーク設定]] 3-3）。
- **DHCPをAPで有効化しない**：有効にすると各VLANのRTX1300 DHCPと競合します。
- **ヤマハLANマップの対象外**：本APはRTX1300のAP一元管理（LANマップ）では管理できません。**単体管理（ローカルWeb GUI）**で運用します（NETGEAR Insightは使用しない）（[[ネットワーク構築提案書]]）。
- **UPS保護**：PoEエクステンダー（給電源）はUPS保護対象に含めます（AP停止＝無線全断のため）。
- **秘匿情報**：SSIDのPSK・管理者パスワードは本ファイルに平文で残さず、パスワード管理台帳で管理します。

## 8. 初期セットアップ手順（★フラットのうちに先にAPを設定）

> **狙い**：APの工場出荷IPは `192.168.0.100`。**PCを 192.168.128.x にすると別サブネットの `192.168.0.100` へは届かない**（フラットSWはサブネット間ルーティングをしない／Discovery ToolはL2で“見える”だけ）。**まだ 192.168.0.x で届く今のうちに** APを `192.168.128.3` 等へ設定してしまうのが最も簡単（Option 1）。

### 8-1. 今（フラットVLAN1・PCは 192.168.0.x）で AP に投入する設定

`http://192.168.0.100/`（Discovery Toolの「Web管理」ボタン可）へ入り、次を設定：

| 項目                  | 値                                                          |
| ------------------- | ---------------------------------------------------------- |
| 管理IP                | **`192.168.128.3 / 255.255.255.0`**、GW `192.168.128.1`（静的） |
| 管理VLAN / Untagged VLAN | **この段階ではまだ変更しない**。最後（8-2 手順3）で **Management VLAN=10／Untagged VLAN=10（ネイティブ）** に設定 |
| SSID `Office-WiFi`  | **VLAN 10** ／ WPA2/3＋PSK（要記入）                              |
| SSID `Develop-WiFi` | **VLAN 20**                                                |
| SSID `Guest-WiFi`   | **VLAN 30** ／ クライアント分離ON                                   |
| 無線                  | **ON**（BE9400は社内AP。OFFにするのはHGW側だけ）                         |

> **最終形は「VLAN10＝ネイティブ（アンタグ）」**：AP側 **Management VLAN=10／Untagged VLAN=10**、XS508TM Port5 は **VLAN10=アンタグ(U)+PVID10、20/30=タグ**。管理・OfficeはVLAN10をアンタグで送受するため、**フラット→VLAN移行が滑らか**（アンタグのままIPだけ 192.168.0.100→192.168.128.3 に変わる）。設定はフラットで先に入れて確認し、IP/VLAN変更は“最後”に行う。

### 8-2. 順序（ロックアウトしない）

1. **今（フラット・PCは 192.168.0.x）**：`192.168.0.100` で 8-1（管理IP `.3`／SSID→VLAN／無線ON）を投入 → Apply（**管理VLANはまだ変更しない**）
2. **PCを `192.168.128.x`** に変更 → `https://192.168.128.3/` に再到達（まだフラットVLAN1）し、SSID等を**確認**
3. **最後に IP=192.168.128.3／GW=192.168.128.1／Management VLAN=10／Untagged VLAN=10** に変更 → Apply（APは 192.168.128.3・VLAN10へ。フラットでもアンタグなので **PCを 192.168.128.50/24** にすれば `https://192.168.128.3/` で再接続可）
4. **XS508TM を設定**（Port5＝VLAN10アンタグ(U)+PVID10・20/30タグ／作業PCのPort4＝VLAN10アンタグ・PVID10／管理VLAN10・`.2`。→ [[config_XS508TM]] 7章）
5. PCをVLAN10（XS508TM Port4）にして、AP `192.168.128.3`・各SSIDのVLANを最終確認（→ 6章）。見失ったら **AP Reset長押し**で `192.168.0.100` に復帰（復旧口）

> ポイント：VLAN10をアンタグ（ネイティブ）に統一したので、AP管理はフラット(VLAN1)でもVLAN化後でも**アンタグのまま**。切替はPort5のPVIDがVLAN10になるだけで滑らか。
