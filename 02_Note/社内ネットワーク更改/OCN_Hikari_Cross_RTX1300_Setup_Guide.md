# OCN光 フレッツ光クロス（10G）における 機器構成・設定ガイド

## 1. 概要・構成方針

本ドキュメントは、NTT東日本の「フレッツ 光クロス（10Gbps）」およびプロバイダ「OCN光 IPoE（固定IP1）」の環境において、提供されるホームゲートウェイ（XG-100NE）を**実質的なブリッジ機器（メディアコンバーター）**として扱い、メインルーターである **YAMAHA RTX1300** にルーター機能、VLAN制御、および各種VPNサーバー機能を一元集約するための構成ガイドです。

従来のPPPoE環境における「HGWのブリッジモード運用」と同等のネットワーク構造を、IPoE（IPv6）環境下で再現（パターンB：RTX1300での固定IP直接終端）することを目的としています。

```text
             │
             │ (10Gbps 光回線)
             ▼

   ・Wi-Fi機能: OFF

   ・固定グローバルIPv4アドレスを直接保持
             │
             ├───────────────────────────┬───────────────────────────┐
             ▼                           ▼                           ▼
 🔐 AWS VGW (拠点間IPsec)      📱 リモート端末 (L2TP/IPsec)    🔀 社内VLAN ネットワーク
 (IKEv1/v2, BGP動的ルーティング)  (PC / スマホ / モバイル)        (タグVLAN / ポートVLAN)
```

## 3. 機器スペックおよび役割分担

### 3.1 機器仕様と役割
| 項目 | NTT XG-100NE | YAMAHA RTX1300 |
| :--- | :--- | :--- |
| **役割** | 回線引き込み・IPv6パススルー | メインルーター・VPNサーバー・VLAN管理 |
| **10Gポート** | LAN4 (10GBASE-T × 1) | PORT 10 (10GBASE-T/SFP+ 複合 × 2) |
| **1Gポート** | LAN1〜3 (1000BASE-T × 3) ※未使用 | PORT 1〜8 (1000BASE-T × 8) |
| **Wi-Fi** | OFFに設定 | 不要 (別途APを配置) |
| **VLAN機能** | 非対応 | **対応** (IEEE 802.1Q タグVLAN / ポートVLAN) |
| **VPNサーバー** | 非対応 | **対応** (L2TP/IPsec, IPsec IKEv1/v2, BGP等) |

## 4. 各機器の詳細設定手順

### 4.1 XG-100NE の設定（実質的ブリッジ化）
1. **設定画面へのアクセス**
   * ブラウザから `http://192.168.1.1/` または `http://ntt.setup/` にアクセス。
2. **Wi-Fi（無線LAN）機能の停止**
   * 無線LAN設定画面にて、2.4GHzおよび5GHzのSSID発信をすべて **OFF（無効）** に変更します（混信・不要電波の防止）。
3. **接続・配線**
   * 背面の **「LAN4」ポート（10G対応）** にのみLANケーブル（Cat6A/Cat7）を接続し、RTX1300のWANポート（ポート10）へ接続します。
   * LAN1〜3ポートおよび各種ルーター接続設定は使用しません。

---

### 4.2 RTX1300 の設定

#### A. OCNバーチャルコネクト（固定IP1）接続
* **設定方式:** IPoE (IPv4 over IPv6) トンネル設定
* **接続種別:** OCNバーチャルコネクト 固定IP1
* **IPv6取得方式:** フレッツ 光クロスの仕様に基づき、**DHCPv6-PD方式**（ひかり電話契約の有無にかかわらずPD方式）を選択。
* **登録情報:** OCNから提供される「固定IPアドレス」「Tunnel Destination」「インターフェースID」等の開通情報を投入し、RTX1300自身にパブリック固定IPアドレスを持たせます。

#### B. VLAN（ネットワーク分割）管理
* RTX1300にてタグVLAN（IEEE 802.1Q）およびVLAN間ルーティングを設定。
* XG-100NE配下ではなくRTX1300配下で閉じているため、VLAN 10（社内メイン）、VLAN 20（ゲスト用）、VLAN 30（IoT機器用）などの柔軟なアクセス制御・DHCP配信が可能です。

---

## 5. VPNサーバー機能の構築・運用

RTX1300がパブリック固定IPを直接保持しているため、ポート転送（静的NAT）を挟むことなく、非常に安定したVPN環境を構築できます。

### 5.1 リモートアクセスVPN (L2TP/IPsec)
* **対象:** 外部のPC（Windows / Mac）、スマートフォン（iOS / Android）
* **特徴:** 固定IP指定で接続可能なため、DDNS不要で安定した通信を確立できます。
* **主要ポート:** UDP `500` / UDP `4500` (NAT-T) / IPプロトコル `50` (ESP) をRTX1300自身が受信。

### 5.2 拠点間接続VPN (AWS VGW 連携)
* **対象:** AWS VPC (Virtual Private Gateway)
* **方式:** IPsec (IKEv1 / IKEv2)
* **ルーティング:** BGPを用いた動的ルーティング（Dual Tunnel冗長構成）に対応。
* **メリット:** 中間にルーターやNAT処理が存在しないため、Phase1/Phase2のSA確立エラーやNAT Traversal関連のトラブルを回避できます。

---

## 6. まとめ・メリット

1. **二重ルーターの完全回避**
   * XG-100NEでのIPv4ルーター処理をバイパスし、RTX1300が固定IPを直接保持します。
2. **10Gbps帯域の最大活用**
   * XG-100NE (LAN4) ⇔ RTX1300 (PORT 10) を10Gで接続するため、ボトルネックが発生しません。
3. **従来運用（PPPoEブリッジ）からのスムーズな移行**
   * ルーター機能、VLAN、VPNがすべてRTX1300側で完結するため、設計思想を変更せずに光クロスへ移行可能です。
