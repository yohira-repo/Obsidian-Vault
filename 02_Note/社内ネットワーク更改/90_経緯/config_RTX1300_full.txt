# ============================================================================
# YAMAHA RTX1300  統合コンフィグ（一発投入用）
# 出典: config_RTX1300.md（設計の正）。本ファイルは全章を投入順に連結したもの。
#
# 【使い方】
#   1. 下記プレースホルダ <...> をすべて実値へ置換してから投入すること。
#   2. コンソール(SSH/シリアル)へブロック単位で貼り付けるのが安全。
#      まとめて一括投入すると障害切り分けが困難（段階投入版=config_RTX1300_staged.txt 推奨）。
#   3. 末尾の save を実行して確定。
#
# 【投入前に確定させるプレースホルダ】
#   <LOGIN_PASS> <ADMIN_PASS>            : ログイン/管理者パスワード（社内）
#   <GLOBAL_IP>                          : 固定グローバルIPv4＝「お客さまネットワークアドレス(IPv4)」（NAT外側はmap-e自動。値は§8/§10で使用）
#   <AR_URL>                             : アドレス解決システム FQDN URL（Lua SERVER_URL）
#   <AR_ID> / <AR_PASS>                  : アドレス解決システム 認証用共通ID/パスワード（Lua USERNAME/PASSWORD）
#   <AR_HOST>                            : アドレス解決用ホスト名（Lua HOSTNAME）
#   <BR_IPV6>                            : BR IPv6アドレス（確認用。明示指定要否は公式固定IP例で確認）
#   （※ <IF_ID>/<TUNNEL_DST> は旧ipip方式の値。map-e方式では不要＝通知されない）
#   （DNSは確定済み：OCN指定[東日本]210.145.254.170/125.170.93.234 ＋ fallback 8.8.8.8/1.1.1.1）
#   <MAC_01>..<MAC_12>                   : DHCP予約対象PCのMAC（実機確認）
#   <L2TP_PSK>                           : L2TP/IPsec 事前共有鍵（社内）
#   <PASS_xxx>                           : 各VPNユーザーのパスワード（社内）
#   <AWS_*>                              : AWS VGW関連（★今回スコープ外・11章）
#
# 【最重要の注意】
#   - LAN2 は必ず ra-prefix@lan2（RA方式）。dhcp-prefix@ にするとIPv4が通らない。
#   - VLAN間フィルタは静的passが動的filterより前にある順序を厳守（8章/9章）。
#   - AWS拠点間VPN(11章)は切替当日は投入しない（事後対応）。

# ============================================================

#   追加ユーザー: login user <名前>（対話でPW）／ user attribute <名前> administrator=2（管理権限）
#   昇格PW（対話入力）: administrator password → Old_Password:(初期は空=Enter) → New_Password: <ADMIN_PASS> → 確認

# 3. インターフェース
# ============================================================
# --- 3-1. LAN1: 保守セグメント ---

# ============================================================
# 4. map-eトンネル（OCN固定IP1／アドレス解決システム）
#   方式＝map-e＋Lua。固定IPv4はOCN公式Luaでアドレス解決システムへ登録して適用。
#   手動ipip（対向/IF_ID直書き）は使わない。
# ============================================================
tunnel select 1
 tunnel encapsulation map-e
 tunnel map-e type ocn
 ip tunnel mtu 1460
 ip tunnel tcp mss limit auto
 ip tunnel nat descriptor 1
 tunnel enable 1
ip route default gateway tunnel 1
# アドレス解決システムへの登録（OCN公式 ocn_address_notification.lua を emfs:/ に配置）
#   SERVER_URL=<AR_URL> / USERNAME=<AR_ID> / PASSWORD=<AR_PASS> / HOSTNAME=<AR_HOST> / IPv6_IF="LAN2"
schedule at 1 startup * lua emfs:/ocn_address_notification.lua
# ★要検証：BR(<BR_IPV6>)明示指定要否 / HGW配下(RA)でのmap-e成立 / ipv6 lan2行 → 公式固定IP例で確定


# ============================================================
# 5. NAT（固定グローバルIPでのNAPT。固定IPv4はmap-eで自動適用）
# ============================================================
nat descriptor type 1 masquerade
nat descriptor address outer 1 map-e
nat descriptor address inner 1 auto
# Web公開(www/https静的NAT)は今回移植しない。必要時に下記を追加:
# nat descriptor masquerade static 1 301 <公開サーバIP> tcp www
# nat descriptor masquerade static 1 302 <公開サーバIP> tcp https

ipsec transport 1 1 udp 1701
tunnel select 1000

  ipsec sa policy 1 1 esp aes-cbc sha-hmac
